# Compact Security-Evidence Experiments - Publication-Corrected

This family contains retained CSE-CIC-IDS2018 evidence for admission rejection,
digest binding, tamper detection, commitment recomputation, scoped Groth16 /
public-input verification, layered verification overhead, and Sepolia evidence
publication. It is not the authoritative historical predictive-utility bundle.

Publication-facing JSON uses portable locators. Because many retained artifacts
are SHA-pinned, the exact uploaded archive is embedded as
`HISTORICAL_ORIGINAL_BYTES.zip` for historical-byte verification.

Read `PUBLICATION_SCOPE_NOTE.json`, `PUBLIC_INPUT_CHECK_RECONCILIATION.json`,
and `HASH_SEMANTICS.json` before interpreting the evidence.
