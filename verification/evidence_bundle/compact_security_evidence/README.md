# Compact Security-Evidence Bundle

This bundle is selected evidence from the retained compact security-evidence
execution.

`core/` contains selected DP records/ledgers and global AnchorSum metadata.
These files were previously mislabeled under `primary_compact/`; that name was
removed because the historical main predictive-utility output bundle was not
retained.

`signed_reports/` contains selected signed round-manifest and on-chain export
material from the same security-evidence lineage.

This evidence must not be cited as a substitute for the missing historical main
compact predictive-utility bundle.
